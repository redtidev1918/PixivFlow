🔐 认证配置

Pixiv API 需要 OAuth refresh token。获取方式：

pixivflow login             # 有图形界面（浏览器交互）
pixivflow login-headless    # 无图形界面 / 服务器
token 过期时会自动刷新；连续失败会提示重新登录，且不会误删有效凭据。

🎯 下载目标配置

每个下载目标（target）定义「从哪抓什么、抓多少」：

字段说明示例
tags标签数组（多标签为 OR 关系）["水彩", "厚涂"]
limit单次下载数量上限50
minBookmarks最低收藏数筛选2000
startDate / endDate发布日期范围"2025-01-01"
random启用随机模式{ "maxAttempts": 50 }
languageFilter语言过滤（小说）"zh-cn"
随机模式从可用队列中抽取最多 maxAttempts 个作品（默认 50），适合探索式收集。

⏰ 定时任务配置（Cron 速查）

Cron 表达式含义
0 8 * * *每天早上 8:00
0 */6 * * *每 6 小时一次
30 21 * * *每天晚上 21:30
0 9 * * 1每周一早上 9:00
0 0 1 * *每月 1 日 00:00
服务器时区影响调度时间——Docker 部署时通过 TZ 环境变量设置时区（见部署指南）。

💾 存储配置

各类内容的保存目录均可在配置中调整：

  • downloadDirectory — 下载根目录；
  • illustrationDirectory — 插画保存目录；
  • novelDirectory — 小说保存目录。

快速查看与修改：

pixivflow dirs                          # 查看所有目录路径
pixivflow config set downloadDirectory /data/pixiv
pixivflow config                        # 查看完整配置（自动备份原配置）

⚡ 下载性能配置

  • 批量模式自动翻页，页面间隔遵循 API 速率限制；
  • 已下载作品基于 SQLite 历史自动跳过，支持断点续传；
  • 数字 GIF / 图片按显示尺寸解码，降低内存与 GPU 占用（桌面端）。

🌐 网络配置

  • 支持 HTTP(S) 代理环境变量（http_proxy / https_proxy）；
  • Docker 部署时在 docker-compose.yml 中注入代理变量即可让容器内请求走代理；
  • 网络层自带超时与有界指数退避重试；429 会读取 Retry-After 响应头等待。

🖥️ CLI 配置管理命令

命令作用
pixivflow config查看当前完整配置
pixivflow config set <key> <value>设置单项配置（自动备份原文件）
pixivflow status下载统计 + 最近记录
pixivflow health检查配置完整性、目录可写性、连通性
