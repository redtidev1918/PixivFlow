🔐 登录相关

登录失败？

确认账号可正常访问 Pixiv 网页版；网络受限时先在配置中设置代理， 再重新执行 pixivflow login。

认证失败或 Token 过期？

refresh token 失效时会明确提示。重新运行 pixivflow login（或服务器上的 pixivflow login-headless）即可；token 的自动刷新在有效期内由 App 自己完成， 无需人工干预。

📥 下载相关

找不到匹配的作品？

  • 检查标签拼写是否与 Pixiv 完全一致（注意全半角）；
  • 降低 minBookmarks 或放宽日期范围；
  • 用 URL 直接下载验证目标作品本身可访问。

下载速度慢或经常失败？

  • 单次 limit 不要设得过大，配合 delay 让请求更平滑；
  • 受限网络建议配置 HTTP 代理；
  • 反复失败的作品会被自动跳过并记录，不会阻塞整个队列。

遇到已删除或私有的作品？

这类作品会被识别为「不可下载」并智能跳过，不影响其余下载任务； 这是预期行为而非故障。

⏰ 定时任务相关

定时任务没有运行？

  • 时区：容器内默认 UTC，请通过 TZ 环境变量设置为本地时区；
  • 进程存活：pixivflow scheduler 必须持续运行 （Docker / PM2 / systemd 任选其一托管）；
  • Cron 表达式：检查是否使用了不存在的字段组合。
