🔗 URL 直接下载（最简单）

无需修改任何配置文件，直接粘贴链接即可下载。支持的 URL 类型：

类型URL 格式
插画https://www.pixiv.net/artworks/{id}
小说https://www.pixiv.net/novel/show.php?id={id}
小说系列https://www.pixiv.net/novel/series/{id}
用户作品（该用户全部作品）https://www.pixiv.net/users/{userId} ⭐
pixivflow download --url https://www.pixiv.net/artworks/123456789

🖼️ 单作品与小说下载

单张插画

通过 ID 或 URL 定位单个插画，自动按画师与标题归档保存。

小说

支持小说正文下载为文本文件；系列小说会连续抓取全部分话。语言过滤可在 配置中设定，检测不匹配的作品会被记录并跳过（而非报错中断）。

批量与分页

用户作品、标签搜索等批量模式会自动翻页抓取，直到达到 limit 上限或数据耗尽；每批次之间有间隔控制以遵守 API 速率限制。

🔍 智能筛选

在配置文件的下载目标（target）中可组合使用以下筛选条件：

条件说明示例
minBookmarks最低收藏数"minBookmarks": 1000：只要收藏 ≥1000 的作品
startDate / endDate发布日期范围"startDate": "2025-01-01"
作品类型插画 / 漫画 / 小说分开定向不同 target 分别配置
limit单次下载数量上限"limit": 50
筛选在规划阶段完成——不会请求已筛除作品的详情，节省 API 配额。

🎯 实际应用场景

场景 1：每日自动收集灵感素材

{
  "schedule": "0 8 * * *",
  "targets": [{
    "tags": ["背景", "光影"],
    "minBookmarks": 2000,
    "limit": 20
  }]
}

每天早上 8 点自动收集高质量背景素材，第二天直接翻阅本地文件夹。

场景 2：服务器定时收集特定标签

配合 Docker 部署 + volume 挂载，把下载目录指向 NAS 或网盘同步文件夹， 多端都能看到最新收藏。

场景 3：多标签 OR 搜索

一次填入多个标签（如 ["水彩", "厚涂"]），命中任一标签的作品都会进入队列， 再用 minBookmarks 保证质量底线。

场景 4：排行榜批量下载

结合每日排行接口与 limit，把当天榜单前 N 名收入囊中。
