核心能力一览

🔗 URL 直接下载输入 Pixiv URL 即可下载（插画 / 小说 / 用户作品页，v2.0.37+）
🎯 单作品下载通过作品 ID 或 URL 精确下载单个插画或小说
🏷️ 标签搜索按标签搜索，支持精确匹配、部分匹配等多种模式
🎲 随机下载一键下载随机热门标签作品，快速上手体验
⏰ 定时任务Cron 表达式配置：每天 / 每周 / 每月自动下载
🔍 智能筛选按收藏数、日期范围、作品类型等多维度筛选
💾 自动去重SQLite 记录下载历史，自动跳过已下载作品
🔄 断点续传中断后自动恢复，无需从头开始
🛡️ 错误处理自动重试、错误恢复，智能跳过已删除 / 私有作品

🚀 三步上手

  1. 安装

    npm install -g pixivflow          # 全局 CLI
pixivflow --help                  # 验证安装

    也可以直接使用 Docker 部署（推荐服务器场景）。

  2. 登录 Pixiv 账号

    pixivflow login

    或无图形界面环境使用 pixivflow login-headless。

  3. 开始下载

    # 最简单的方式：粘贴任意 Pixiv 链接
pixivflow download --url https://www.pixiv.net/artworks/123456789

# 按配置文件中的下载目标执行
pixivflow download

# 启动定时任务
pixivflow scheduler

完整的命令列表、URL 类型支持说明见 使用教程；配置项详见 配置参考。
