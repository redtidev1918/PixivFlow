🐳 Docker Compose 部署（推荐）

快速开始

git clone https://github.com/redtidev1918/PixivFlow.git
cd PixivFlow
cp docker-env.example .env      # 按需修改配置
docker compose up -d

首次登录 Pixiv 账号

docker compose exec app pixivflow login-headless

常用运维命令

命令作用
docker compose logs -f app实时查看下载日志
docker compose restart app重启服务
docker compose stop停止全部服务
docker compose exec app pixivflow status查看下载统计
下载目录建议通过 volume 挂载到 NAS / 网盘同步文件夹，实现多端共享收藏。

🔁 方式 1：PM2 管理（无 Docker）

npm install -g pm2
npm install -g pixivflow

pm2 start pixivflow --name pixivflow -- scheduler
pm2 save && pm2 startup   # 开机自启
pm2 logs pixivflow        # 查看日志

🔁 方式 2：systemd 服务

创建服务单元文件：

# /etc/systemd/system/pixivflow.service
[Unit]
Description=PixivFlow Scheduler
After=network-online.target

[Service]
Type=simple
User=youruser
WorkingDirectory=/opt/pixivflow
ExecStart=/usr/bin/node dist/index.js scheduler
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable --now pixivflow
journalctl -u pixivflow -f    # 查看日志

⏰ 时区提示

Cron 定时任务依赖容器/系统时区。Docker 用户请在 docker-compose.yml 中设置： TZ=Asia/Shanghai，否则调度会按 UTC 时间执行。
