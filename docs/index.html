🐱 PixivFlow

把「刷 Pixiv 手动存图」变成一条命令。批量下载插画与小说,按标签、收藏数、日期筛选,Cron 定时自动收集——CLI 与 WebUI 双形态,Docker 部署即开即用。

📖 五分钟上手教程 ⌨️ 直接看用法 📦 npm 🐙 GitHub

Node.js 22.12+ · TypeScript · MIT License · Windows / macOS / Linux / Docker / Android(Termux)

三步跑起来

  1. 安装 CLI

    npm install -g pixivflow
pixivflow --help   # 出现帮助信息即成功

    服务器推荐 Docker Compose;Android 用户走 Termux 路线。

  2. 登录一次 Pixiv 账号

    pixivflow login                 # 桌面环境,浏览器授权
pixivflow login-headless -u 用户名 -p 密码   # 无图形界面的服务器

    凭据写入本地配置,之后所有命令复用,详见 登录指南。

  3. 粘贴链接,直接下载

    pixivflow download --url https://www.pixiv.net/artworks/123456789

# 或者按配置批量收集:
pixivflow download
# 挂机自动化:
pixivflow scheduler

    文件默认保存在 ./downloads,运行 pixivflow dirs 查看实际位置。
